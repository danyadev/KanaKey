# KanaKey

KanaKey is a compact Japanese kana typing trainer.
It teaches kana through real-word batches, tracks per-kana progress,
and supports IME-first typing with a keybr-style input surface.

## Scripts

- `yarn dev` - start Vite dev server
- `yarn test` - run Vitest behavior tests
- `yarn build` - type-check and build production assets
- `yarn generate-words` - generate ranked words.json file
- `yarn optimize-kana` - calculate the best kana progression depending on existing words in words.json
